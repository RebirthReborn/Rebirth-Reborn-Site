Circular access

When every process points somewhere else

Academic problem→Human-rights / accommodation issue→Internal office→Petition / appeal→Deadline / good-standing barrier→External route→No immediate academic remedy→Back to academic status

I kept being directed to processes that depended on an unresolved academic status, while the routes identified to fix that status were late, advisory, conditional, or unable to solve the immediate return problem.

The point of this page is not that every process was illegitimate. It is that the combined structure could leave the central academic question unresolved while time-sensitive consequences continued to accumulate.

The current request is therefore simple: one current, authorized academic determination that can actually govern the return path.
